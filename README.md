# llm-autism-text-simplification
Plataforma baseada em Inteligência Artificial para simplificação de textos sobre autismo em Linguagem Simples. Abrange os eixos jurídico, saúde, educação e administrativo, tornando normas, laudos e guias acessíveis a pessoas autistas, famílias e profissionais. Disponibiliza o acervo simplificado para consulta pública direta.
